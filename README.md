# Maya

Site interativo sobre como a inteligência artificial pode ajudar a salvar a Mata Atlântica.

## Como usar

Abra o arquivo `index.html` em um navegador ou publique na GitHub Pages do repositório.

## Conteúdo

- Fluxograma interativo com botões
- Explicação sobre IA aplicada à Mata Atlântica
- Sugestões de monitoramento, restauração, prevenção e educação
- Design responsivo para desktop e celular
